# Evidence Directory

This directory stores authentic screenshots captured during probe testing and test case execution.

## Mandatory Screenshot Guidelines (from Handout & Instructions)
1. **Physical Sticky Note**: Your roll number must be clearly visible on a physical sticky note or Post-it affixed to your screen within the captured/cropped area. Digitally inserted text is strictly prohibited by course policy.
2. **Legibility**: Crop to the relevant region showing the input values entered and the system's reaction/error message/charts. Full-desktop screenshots with tiny unreadable text are penalized.
3. **Consistency**: Use a consistent browser (e.g. Chrome or Firefox) and zoom level (e.g. 100%) throughout all captures.
4. **Naming Convention**: Use descriptive filenames matching the probe or test case ID, e.g.:
   - Probes: `PR-001_SignUp_EmptyPassword.png`
   - Test Cases: `TC-EP-001_SignUp_ValidEmail.png`, `TC-BVA-001_SignUp_PasswordLength7.png`
5. **No Synthetic / Placeholder Images**: Only genuine screenshots of tests actually executed by you are placed in this folder.
